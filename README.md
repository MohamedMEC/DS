# DS — AI Web Tutor

An interactive, beginner-friendly tutor for Principles of Data Science.

## Units

1. Linear algebra learning studio: 18 topics, 18 visual labs, experiment missions, NumPy labs, checks and quizzes
2. Probability and Bayes' theorem: 8 topics, from sample spaces through the multiplication rule and total probability to Bayes' theorem
3. Probability distributions and simulation
4. Data preparation, EDA and PCA
5. Statistical modelling and decisions
