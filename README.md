# DS — AI Web Tutor

An interactive, beginner-friendly tutor for Principles of Data Science.

## Units

Every unit is a complete learning studio: guided concept cards (meaning → tiny example → formula → ML relevance), a live interactive lab per topic, hands-on experiment missions, a NumPy/Python code panel, a misconception buster, and an end-of-unit mastery quiz.

1. Linear algebra: 15 topics, 15 visual labs, 45 experiment missions
2. Probability and Bayes' theorem: 6 topics from sample spaces to Bayes' theorem
3. Probability distributions and simulation: Binomial, Poisson, Normal, the Central Limit Theorem and the Law of Large Numbers
4. Data preparation, EDA and PCA: missing data, outliers, descriptive stats, correlation, scaling and PCA
5. Statistical modelling and decisions: regression, multiple regression, logistic regression, hypothesis testing, t-tests and ANOVA
